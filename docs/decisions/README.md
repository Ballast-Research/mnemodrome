# Decisions

Architecture decision records (ADRs) for Mnemodrome.

Rules: each ADR is `ADR-NNN-short-title.md`, numbered in order, at most 100 lines,
with the sections Context, Decision, Consequences and Supersedes. A new ADR is
`proposed`; only a maintainer sets it to `accepted`. An accepted ADR is not edited:
it is changed by a new ADR that supersedes it, and the old one is marked
`superseded by ADR-NNN`.
